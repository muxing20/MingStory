崇祯<br>
一 <br>
崇祯十七年正月初三，北京下了开年第一场雪。

李明睿跪在德政殿冰冷的金砖地上，膝盖疼得发麻，但他不敢动。他已经跪了小半个时辰，崇祯还没叫他起来。

殿里烧着地龙，暖得发燥。御案上堆着两摞奏折，一摞是辽东的军报，一摞是陕西的告急。崇祯坐在案后，手里捏着一份，半天没翻页。

“李明睿，”崇祯终于开口，声音不大，但在空旷的大殿里格外清晰，“你说南迁，是让朕放弃北京？”

李明睿把头埋得更低：“臣不敢。臣所言南迁，是请陛下巡幸南京，以图恢复。北京城高池深，可留太子或重臣固守。陛下在南京，江南财赋可保无虞，天下人心亦有所系。”

崇祯沉默了很久。

窗外有乌鸦叫了一声，扑棱棱飞走了。殿角的西洋自鸣钟滴答滴答地走着，那是万历年间利玛窦进贡的，快四十年了，还走得很准。崇祯听着那个声音，忽然想起一件事：去年秋天，他梦见太祖朱元璋站在煤山上，指着北京城说了四个字。

他没听清。醒来之后，他琢磨了好几天，觉得太祖说的应该是“不可弃”。

“李明睿，”崇祯的声音突然冷了下来，“你让朕南迁，是想让朕背上弃宗庙的骂名吗？”

李明睿浑身一颤，额头触地：“臣万死不敢！臣是为大明江山社稷——”

“够了。”崇祯把奏折往案上一扔，“此事再议。你下去吧。”

李明睿退出去了。德政殿又安静下来，只剩下自鸣钟的滴答声。

崇祯站起来，走到殿门口。雪下得不大，细细密密的，把宫里的琉璃瓦盖了一层白。他伸手接了几片雪花，看着它们在掌心化成水。

他想起十七年前，自己刚即位的时候，也是这样一场雪。那时他十七岁，站在乾清宫前，觉得自己什么都能做。扳倒魏忠贤，只用三个月。他以为，只要自己够勤政、够节俭、够用心，大明就能中兴。

十七年过去了。他每天批奏折到深夜，宵衣旰食，龙袍打补丁，不近女色，不修宫殿。他把能做的都做了，熬的四十岁不到却两鬓斑白。可辽东丢了，陕西反了，河南丢了，湖广丢了。他杀了袁崇焕，换了五十个内阁大学士，杀了七个兵部尚书。他越努力，局面越坏。

“朕到底做错了什么？”

他问自己，也问天。没人回答。

二 <br>
李明睿回到府中，一夜没睡。

他坐在书房里，把南迁的路线图翻来覆去地看。从北京到南京，走驿道，经保定、真定、顺德、大名、济宁、徐州、淮安、扬州，过长江到南京。全程两千余里，轻车简从，快马加鞭，半月可至。若携百官、奉宗庙，则非一月不可。

只要崇祯下决心，完全来得及。

但李明睿知道，崇祯不会轻易下这个决心。他太了解这位皇帝了。崇祯不是不想南迁，是不敢独自承担南迁的骂名。他要大臣们公开上疏，公请南迁，这样将来史书上写的是“群臣劝进”，而不是“天子弃国”。

可那帮大臣，谁敢开这个口？

陈演是首辅，但陈演只会揣摩圣意、明哲保身。魏藻德是次辅，但魏藻德比陈演还滑，见人说人话，见鬼说鬼话。李建泰倒是敢说话，但他去年督师山西，还没出京就跑了回来，现在说话没人信。

李明睿想起一件事。去年夏天，他私下问过陈演：“如果李自成打到北京，怎么办？”

陈演说：“李自成不过流寇，成不了气候。”

李明睿又问：“如果真打到了呢？”

陈演笑了笑：“那便降了。”

李明睿当时以为陈演在开玩笑。后来他才知道，陈演不是开玩笑。

这个朝廷，从上到下，没有几个人真心想救。

李明睿把路线图收起来，叹了口气。他想起崇祯刚即位时的样子，那时崇祯才十七岁，站在乾清宫前，眼神亮得像刀子。扳倒魏忠贤，只用三个月。满朝文武都说：中兴有望。

十七年过去了。那个眼神亮得像刀子的少年，现在成了一个多疑、刚愎、好面子的中年人。

三<br>
二月初八，李自成攻克太原，北京西边已无险可守。

消息传来，廷议沸扬。左都御史李邦华上疏，请崇祯南迁，并请太子先赴南京抚军。李明睿也再次上疏，言辞比正月初三那次更急迫。

崇祯把奏疏下发各部讨论。

朝堂上，陈演第一个站出来反对。他说京师乃天下根本，陛下若南迁，人心必散，北方必失。太祖陵寝在此，宗庙社稷在此，岂能弃之而去？

兵科给事中光时亨紧随其后，大声斥责南迁之议为“邪说”，扬言“不杀李明睿，不足以安人心”。

崇祯听着，脸色铁青。他盯着光时亨，说了一句让所有人都没想到的话：“光时亨阻朕南行，本应处斩，姑饶这遭。”

大殿里一下子安静了。

但光时亨没有退缩，陈演也没有退缩。魏藻德跟着跪下，说臣等誓与京师共存亡。李建泰也跪下了，说臣愿捐家财、招募死士。

崇祯看着跪了一地的大臣，忽然笑了。那笑容很苦，像吞了黄连。

“好，好，你们都是忠臣。”他站起来，袖子一甩，“此事作罢。”

他走出大殿，外面的雪已经停了。阳光照在雪地上，刺得他睁不开眼。

李邦华的建议其实是个折中方案：皇帝可以留在北京，先让太子去南京。这样既保住了法统，又不算“弃国”。但崇祯连这个方案也没有采纳。他既不肯自己走，也不肯让太子走。他怕太子走了，自己就成了空架子；又怕太子不走，万一城破，父子俱亡。

他什么都想要，最后什么都没保住。

四<br>
二月，李自成在西安称帝，国号大顺。

消息传到北京，崇祯在乾清宫坐了一整夜。

他翻着案上的奏折，越翻越心凉。陕西的、河南的、湖广的，全是告急。李自成已经控制了西北、中原、湖广，兵锋直指山西。山西一破，北京就是孤城。

他拿起一份奏折，是山西巡抚的。上面写着：“贼势浩大，官军望风而溃。太原危急，请朝廷速发援兵。”

援兵？哪来的援兵。京营号称十万，实际能打仗的不到三万。关宁军在山海关，吴三桂倒是能打，但吴三桂要钱。左良玉在武昌，手里有二十万兵，但左良玉不听调遣。江北四镇，各怀鬼胎。

崇祯把奏折放下，揉了揉太阳穴。他已经三天没睡好觉了。

“王承恩，”他叫了一声。

王承恩从殿外进来，跪在地上：“皇爷。”

“你说，”崇祯的声音很轻，“朕如果南迁，天下人会怎么说？”

王承恩愣了一下，然后说：“皇爷，天下人说什么不重要。皇爷在，大明就在。”

崇祯看了他一眼。这个老太监，从他还是信王的时候就跟着他，二十多年了。王承恩不识字，不懂治国，但王承恩知道一件事：皇帝活着，比什么都重要。

“你去把李明睿叫来。”

李明睿来了。崇祯看着他，说了一句让李明睿差点哭出来的话：“汝意与朕合，但外边诸臣不从，奈何？”

李明睿跪在地上：“陛下，天命微密，当内断圣心，勿致噬脐之忧。”

崇祯沉默了很久。他想起光时亨的那句“邪说”，想起陈演跪在地上说的“誓与京师共存亡”，想起自己十七年来每一次该硬的时候软、该软的时候硬。

“你去拟旨。”他说。

李明睿刚走到殿门口，崇祯又叫住了他：“等等。太子留在北京。”

李明睿愣住了：“陛下，太子留北京太危险了。万一——”

“没有万一。”崇祯打断他，“朕带太子走，就是弃宗庙。太子留北京，朕是巡幸南京。这是朕的底线。”

李明睿张了张嘴，什么也没说出来。他忽然明白了：崇祯到这个时候，还在乎面子。他要南迁，但不能让人说他“逃跑”。他要把太子留下，好向天下人证明：朕只是去南京办公，不是弃国而逃。

李明睿走出乾清宫的时候，天已经大亮了。他回头看了一眼，崇祯还站在殿门口，瘦削的身影在晨光中拉得很长。

那是他最后一次见崇祯。

五<br>
三月，吴三桂接到勤王诏书，率关宁军从宁远入关。三月十六日抵达山海关，二十日到达河北丰润。

他在丰润得知了北京陷落的消息。

吴三桂在丰润停了两天，然后掉头返回山海关。不是他不想救，是已经来不及了。

三月十七，李自成兵临北京城下。

三月十八，太监曹化淳打开彰义门，迎贼入城。

三月十九，崇祯在煤山自缢。身边只有王承恩。崇祯在衣襟上写下血书：“朕自登极十七年，逆贼直逼京师，虽朕薄德匪躬，上干天咎，皆诸臣之误朕也。朕死无面目见祖宗于地下，去朕冠冕，以发覆面，任贼分裂朕尸，勿伤百姓一人，百官俱赴东宫行在。”王承恩在旁边的海棠树上自缢殉主。

太子朱慈烺没有走成。北京城破时他被李自成俘虏，李自成封他为宋王。后来李自成败退西撤，朱慈烺在乱军中失踪，从此下落不明。弘光政权追谥他为献愍太子。

陈演献银四万两求降，李自成收了他的银子，但后来还是把他杀了。魏藻德被刘宗敏拷打五日，死在大顺军的夹棍之下。光时亨后来逃到江南，被南明朝廷以“阻迁”之罪处死。

那些说“誓与京师共存亡”的人，陈演没有共存亡，魏藻德没有共存亡，光时亨也没有。李建泰倒是投降了，后来被清军所杀。

而崇祯，那个怕背骂名的皇帝，真的死在了北京。

他怕了一辈子的骂名，最后用死换来了一个“烈”字。

六<br>
李明睿没有死在北京，也没有死在南京。

北京陷落时他在南方。后来弘光朝建立，他曾在朝中任职。再后来清军南下，弘光政权覆灭，李明睿在顺治初年被清廷召为礼部左侍郎，不久因事革职。

他回了南昌老家，晚年蓄养家妓，康熙十年去世，年八十七。

他没有投水自尽，没有为大明殉节。他活了下来，活了很久，活到看着明朝彻底成为历史，活到看着清朝坐稳了江山。

他有时候会想起崇祯，想起那个站在德政殿门口、接雪花的中年人。

他想：如果当时崇祯南迁了，会怎样？

南京是南都，有六部，有完整的政治体系。江南有财赋，有足够的粮饷。长江有天险，有水师。如果崇祯在南京，法统就是统一的，弘光、隆武、永历这些政权就不会互相攻伐。哪怕只是划江而治，也比被一锅端强，先成南北对峙之势，再图北伐。

但历史没有如果。

李明睿晚年很少跟人提起南迁的事。偶尔有故人来访，酒喝到半醉，他会说一句：“先帝……本可以走的。”

然后就不再说了。

七<br>
三百多年后，南京明故宫遗址公园。

这里只剩下几块石柱础和一段残墙。当年宏伟的奉天殿、华盖殿、谨身殿，早已在曾国藩与长毛的激烈战斗中荡然无存。游客们三三两两地走过，拍照、聊天，这里是北京紫禁城的蓝本，是永乐大帝派三宝太监下西洋的地方，是宽永舆全图描绘的世界中帝国的心脏，也是无数历史爱好者梦想着“如果崇祯南迁”的地方。

走出遗址公园，外面是车水马龙的南京街头，新盖的地铁站里有一幅壁画，画的是永乐年间万国来朝的场景。朱棣坐在南京奉天殿上，郑和站在他身边，各国使节跪了一地。画得很热闹，很辉煌。

我站在壁画前看了很久。

我想起李明睿，想起他晚年蓄养家妓、闭口不谈往事的那些年。他活到了康熙十年，明朝亡了快三十年。三十年里，他有没有在某一个瞬间想过：如果正月初三那天，崇祯没有犹豫；如果二月初八那天，光时亨没有喊出“邪说”；如果李邦华的折中方案被采纳，太子先走了——历史会不会不一样？

大概会。大概不会。

崇祯的悲剧，不只是他一个人的悲剧。他多疑、刚愎、好面子，但这些性格缺陷之所以致命，是因为他面对的是一套烂到根子里的制度：文官党争、财政畸形、卫所崩坏、宗室寄生。这些问题从朱元璋时代就开始积累，到崇祯手上，已经积重难返。

他不是不想救，是不知道该先救哪个。他像一个站在漏水的船上的人，手里拿着锤子和钉子，却不知道该先补哪个洞。他补了辽东，陕西漏了；补了陕西，河南漏了；补了河南，江南的税又收不上来。他越补越忙，越忙越乱，最后连自己都掉进了水里。

而船上的其他人——陈演在抢木板，光时亨在凿船底，魏藻德在假装看不见水，李邦华在喊“先让太子坐小船走”，但没有人听。

明朝的灭亡，不是崇祯一个人的错。相比其他末代帝王，崇祯算是勤政的。但崇祯的悲剧在于：他既不够好到能救亡，也不够坏到能摆烂。他卡在中间，挣扎了十七年，最后把自己和整个王朝一起耗死了。

历史就像那场正月初三的雪，下过了，化了，了无痕迹。

但有些东西，不应该被忘记。

比如那个本该南迁、却最终没有南迁的冬天。比如一个制度烂到根子的时候，再勤政的皇帝也救不回来。比如一个能在煤山上写下“勿伤百姓一人”的皇帝，却不敢在活着的时候说一句“朕要南迁”。
